Mostra le webcam time-lapse Viewlapse: foto attuale, archivio per giorno, prima/dopo, grafico di temperatura e umidità, elenco e mappa.

== Description ==

Blocchi `viewlapse/foto`, `viewlapse/archivio`, `viewlapse/confronto`, `viewlapse/grafico`, `viewlapse/elenco` e shortcode `[viewlapse_foto]`, `[viewlapse_archivio]`, `[viewlapse_confronto]`, `[viewlapse_grafico]`, `[viewlapse_elenco]`.
Le chiamate al portal partono dal server (la chiave non arriva al browser), con cache nei transient. Le foto restano sul portal: nessun file nella libreria media.
Configurazione in Impostazioni → Viewlapse Webcam. Documentazione completa nel README del repository.

Leaflet 1.9.4 (BSD-2-Clause) è incluso in assets/vendor/leaflet.
